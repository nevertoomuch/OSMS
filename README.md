### Лабораторная работа №2
**Тема:** Проектирование радиопокрытия мобильных сетей. Модели распространения сигналов. Бюджеты каналов.  
**Краткое содержание:** Расчёт бюджетов восходящего (UL) и нисходящего (DL) каналов с определением максимально допустимых потерь $MAPL$; сравнение трёх моделей распространения (UMiNLOS, COST231-Hata, Walfish-Ikegami) и выбор модели для макросот и микро-/фемтосот. Определение радиуса соты как точки пересечения кривой потерь $PL(d)$ с уровнями $MAPL$ и расчёт требуемого количества базовых станций для покрытия территорий 100 км² и 4 км². Реализация расчётов и построение графиков на Python (NumPy, Matplotlib).
